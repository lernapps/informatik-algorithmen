Glossar

Die Begriffe dieser App, von A bis Z, jeder mit der Seite, die ihn erklärt.

Algorithmus

Ein Algorithmus ist eine genaue Anleitung (Handlungsvorschrift) aus endlich vielen Schritten, die eine Aufgabe löst. Wer ihn ausführt, muss nichts raten.

Erklärt auf der Seite Was ist ein Algorithmus?

bedingte Wiederholung

Eine bedingte Wiederholung führt den Schleifenrumpf aus, solange die Bedingung wahr ist. Kiko prüft die Bedingung vor jedem Durchlauf. Ist sie falsch, hört die Wiederholung auf, auch schon vor dem ersten Durchlauf.

Erklärt auf der Seite Bedingte Wiederholung

Bedingung

Eine Bedingung ist eine Frage, auf die es nur die Antworten wahr oder falsch gibt (ja oder nein).

Erklärt auf der Seite Verzweigung

Befehl

Ein Befehl ist eine einfache Anweisung, die Kiko kennt und direkt ausführen kann.

Erklärt auf der Seite Sequenz

blockbasierte Programmiersprache

In einer blockbasierten (visuellen) Programmiersprache baust du Programme aus Blöcken, die du zusammensteckst, statt sie zu tippen.

Erklärt auf der Seite Programmieren mit Blöcken

debuggen

Debuggen heißt, Fehler im Programm finden und beheben. Dazu gehst du das Programm Schritt für Schritt durch.

Erklärt auf der Seite Programmieren mit Blöcken

Eigenschaften eines Algorithmus

Ein Algorithmus hat vier Eigenschaften: Er ist endlich beschrieben, eindeutig, ausführbar, und er endet nach endlich vielen Schritten.

Erklärt auf der Seite Eigenschaften von Algorithmen

Endlosschleife

Eine Endlosschleife hört nie auf, weil ihre Bedingung nie falsch wird. Wie auf der Seite Eigenschaften: Ein Ablauf, der nie endet, löst keine Aufgabe, die enden soll.

Erklärt auf der Seite Bedingte Wiederholung

Programm

Ein Programm ist ein Algorithmus, aufgeschrieben in einer Programmiersprache, damit ein Computer ihn ausführen kann.

Erklärt auf der Seite Programmieren mit Blöcken

Schleife

Eine Schleife (Wiederholung) führt Anweisungen mehrmals aus.

Erklärt auf der Seite Zählschleife

Schleifenrumpf

Der Schleifenrumpf sind die Blöcke in der Schleife. Er ist eine Sequenz, die mehrmals ausgeführt wird.

Erklärt auf der Seite Zählschleife

Sensor

Ein Sensor ist der Teil von Kiko, der etwas prüft, zum Beispiel ob vor ihm eine Wand ist.

Erklärt auf der Seite Verzweigung

Sequenz

Eine Sequenz ist eine Folge von Anweisungen, die nacheinander ausgeführt werden, jede genau einmal, in der Reihenfolge, in der sie aufgeschrieben sind.

Erklärt auf der Seite Sequenz

Verzweigung

Eine Verzweigung (wenn … dann … sonst) legt fest, dass ein Algorithmus je nach Bedingung verschiedene Anweisungen ausführt.

Erklärt auf der Seite Verzweigung

Zählschleife

Eine Zählschleife (Wiederholung mit fester Anzahl) führt ihren Schleifenrumpf so oft aus, wie die Zahl sagt.

Erklärt auf der Seite Zählschleife
