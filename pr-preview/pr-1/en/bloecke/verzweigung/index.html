Wall or no wall?

In class 7b's group chat:

Lea: How is Kiko supposed to know if there's a wall in front of it?

Frau Berg: Kiko has sensors. It can ask: “wall ahead?” Depending on the answer, it does something different.

Jona: So one program is enough for all the boards? 😮

Here you learn how a program takes different paths depending on a condition.

Exercise

Kiko faces right on the board and carries out the program on board 2. What happens?

  • Kiko ends on square A. right answer

    Wall ahead? Yes: Kiko turns right and faces down the board. Then the block after the selection: one square forward.

  • Kiko ends on square B.

    You carried out both branches. Kiko does either “then” or “else”, never both.

  • Kiko walks into the wall.

    That would be the “else” branch. But the condition is true, so the “then” branch applies.

  • Kiko turns and stays on its square.

    You forgot the last block. It comes after the selection and is always carried out.

The condition “wall ahead?” is true, so Kiko carries out the “then” branch. The block after it applies in every case.

One question, two paths

The block “wall ahead?” is a condition: Kiko's sensor answers true or false. If true, Kiko carries out the blocks after “then”, if false, those after “else”. After that it carries on with the next block. Kiko can also ask: “way ahead clear?” (the opposite of “wall ahead?”), “at the goal?”, “wall on the left?” and “wall on the right?”.

sensor

A sensor is the part of Kiko that checks something, for example whether there is a wall in front of it.

condition

A condition is a question that can only be answered with true or false (yes or no).

selection

Selection (if … then … else) means that an algorithm carries out different instructions depending on a condition.

Remember

Kiko only ever carries out one branch. So test a program with selection on several boards, so that every branch gets its turn. If there is no “else” (one-sided selection), Kiko skips the “then” part when the answer is false and carries on with the next block.

Try it yourself

Without a computer: use the cards for choices “if ___ then”, “else” and “wall ahead?” to lay out a program. Kiko plays it twice: once with a wall in front, once without.

With a computer: the goal is sometimes up the board, sometimes down. Build a program that works on both boards; the workshop calls them “puzzles”. You need “wall on the left?” for it: open the challenge “Up or down?”

Exercise

Which of these blocks are conditions that can only be true or false?

  • “wall ahead?” right answer

    Either there is a wall in front of Kiko or there isn't.

  • “at the goal?” right answer

    Kiko is on the goal or not. That is true or false too.

  • “move forward”

    That is a command. Kiko does something; it doesn't ask anything.

  • “way ahead clear?” right answer

    The way ahead of Kiko is clear or not. It is the opposite of “wall ahead?”.

  • “How far is the wall?”

    The answer to that is a number, not true or false. Kiko has no such block.

A condition is a question with the answer true or false. Commands and questions about numbers are not conditions.
