Programming with blocks

The cards become blocks. Kiko gets sensors and with them selection, then loops for long paths.

  1. Programming with blocks Command cards become blocks: building, testing and debugging a program in a block-based programming language.
  2. Selection With “if … then … else” Kiko decides what to do depending on a condition: one program for different boards.
  3. Count-controlled loop With “repeat … times” Kiko carries out blocks several times: shorter programs for long paths and patterns.
  4. Condition-controlled loop With “while … do” Kiko repeats blocks as long as a condition is true, even when nobody knows beforehand how often.
