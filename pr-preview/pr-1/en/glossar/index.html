Glossary

The terms of this app, from A to Z, each with the page that explains it.

algorithm

An algorithm is a precise set of step-by-step instructions that solves a problem or completes a task. Whoever carries it out doesn't have to guess anything.

Explained on the page What is an algorithm?

block-based programming language

In a block-based (visual) programming language you build programs from blocks that you snap together instead of typing them.

Explained on the page Programming with blocks

command

A command is a simple instruction that Kiko knows and can carry out directly.

Explained on the page Sequence

condition

A condition is a question that can only be answered with true or false (yes or no).

Explained on the page Selection

condition-controlled loop

A condition-controlled loop runs the loop body while the condition is true. Kiko checks the condition before each pass; if it is false, the loop stops, even before the first pass.

Explained on the page Condition-controlled loop

count-controlled loop

A count-controlled loop runs its loop body as many times as the number says.

Explained on the page Count-controlled loop

debugging

Debugging means finding and fixing bugs (mistakes) in a program. To do it, you go through the program step by step.

Explained on the page Programming with blocks

infinite loop

An infinite loop never stops because its condition never becomes false. As on the page Properties: a process that never ends doesn't solve a task that is meant to end.

Explained on the page Condition-controlled loop

loop

A loop carries out instructions several times. Repeating instructions is called iteration (repetition).

Explained on the page Count-controlled loop

loop body

The loop body is the blocks inside the loop. It is a sequence that is carried out several times.

Explained on the page Count-controlled loop

program

A program is an algorithm written down in a programming language so that a computer can carry it out.

Explained on the page Programming with blocks

properties of an algorithm

An algorithm has four properties: it is finite (finitely described), unambiguous, can be carried out, and it terminates after a finite number of steps.

Explained on the page Properties of algorithms

selection

Selection (if … then … else) means that an algorithm carries out different instructions depending on a condition.

Explained on the page Selection

sensor

A sensor is the part of Kiko that checks something, for example whether there is a wall in front of it.

Explained on the page Selection

sequence

A sequence is a series of instructions that are carried out one after another, each exactly once, in the order in which they are written.

Explained on the page Sequence
